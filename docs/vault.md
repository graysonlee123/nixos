# Vault

All data requiring backup lives in the "vault." Backups are stored as a Restic repository in a GCP bucket (`gs:ggan-vault:/`).

Data lives at `/srv/vault` (owned by `root:root`, world-readable). The restic repo password is managed by sops-nix at `restic/ggantek-archives/password` in `secrets/shared.yaml`.

## Containers

Three `mazzolino/restic` containers handle automated maintenance:

- **vault-backup** -- daily at 6am ET. Retains 7 daily, 8 weekly, 24 monthly snapshots. Sends email notifications on success/failure/incomplete via express-postmark.
- **vault-prune** -- 1st of each month at 4am ET. Reclaims space from forgotten snapshots.
- **vault-check** -- 1st and 16th of each month at 8am ET. Verifies 33% of data per run (full coverage every ~3 cycles).

All three containers are on the express-postmark network for future notification support.

## Authentication

The GCP service account key is generated by sops-nix templates at:

```
/run/secrets/rendered/gcp/ggantek-archives.json
```

## Manual Usage

Set the required environment variables, then interact with Restic:

```shell
export GOOGLE_PROJECT_ID=ggantek-archives
export GOOGLE_APPLICATION_CREDENTIALS=/run/secrets/rendered/gcp/ggantek-archives.json
export RESTIC_PASSWORD_FILE=/run/secrets/restic/ggantek-archives/password

restic -r gs:ggan-vault:/ snapshots
```
